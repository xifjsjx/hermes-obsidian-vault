# Hermes 入库工作流细则

本文件在 SKILL.md 触发后按需读取，包含三类入库任务的完整操作步骤。

## 目录约定

```
<vault>/
├── 00-Inbox/       待分拣暂存（ima 同步、未分类内容先进这里）
├── 10-盲区库/      A级盲区笔记（核心价值区），按学科分子目录
│   ├── 数学/  物理/  化学/  生物/  语文/  英语/
├── 20-学科笔记/    焊链完成后的模块骨架与体系笔记
├── 30-日记/        每日复盘（vault.py daily 自动维护）
├── 40-MOC/         索引地图（vault.py index 自动生成，勿手改）
└── 99-归档/        已掌握、不再活跃的笔记
```

## 任务一：盲区精炼入库（最高频）

触发：用户发来 Kimi 聊天记录、复习截图文字、或口头描述"今天卡在哪"。

1. **提取**：从材料中列出全部盲区点，每个压缩成 ≤15 字核心短句（如"催化剂不改变化学平衡K"）。
2. **去重**：对每个盲区执行 `vault.py find <vault> <关键词>`。
   - 已有同主题笔记 → 合并：在原笔记补充新理解/新错题，更新 frontmatter 的 `status` 与 `created`，不新建。
   - 无相关笔记 → 新建。
3. **写入**：`vault.py new <vault> 10-盲区库/<学科>/<标题>.md --type 盲区 --subject <学科> --status 待消化 --source kimi --tags 盲区,<章节>`
4. **正文结构**（必须三层，禁止只甩结论）：
   - `> [!tip] 核心锚定`：≤15 字短句，单独成块
   - `## 机制`：先裸讲逻辑推导，再给比喻（比喻后标注"⚠️ 脱钩：比喻仅助记，不等于原理"）
   - `## 陷阱与边界`：常见考法变形、易混点
   - `## 关联`：≥1 条 wikilink 指向相关盲区或骨架笔记
5. **复盘登记**：`vault.py daily <vault> --text "- 入库盲区：[[标题1]]、[[标题2]]"`

## 任务二：ima 笔记同步

触发：用户发来 ima 笔记链接或导出的笔记文本。

1. 逐条拆分为主题单元。
2. 每条按任务一第 2-4 步执行（去重 → 写入，`--source ima`）。
3. 无法归类或信息不全的先放 `00-Inbox/`，在当日日记记录待办。
4. 同步完成后回报：新建 N 篇、合并 M 篇、暂存 Inbox K 篇。

## 任务三：焊链成果归档（周末网状重建后）

触发：用户完成某模块焊链，要求录入骨架。

1. 骨架笔记写入 `20-学科笔记/<学科>/<模块>.md`，`--type 骨架`，正文含：
   - 公式/流程骨架（用户裸默写版本，AI 补的缺口用 `> [!warning] 原为缺口` 标出）
   - 典型题锚点（只记题眼与突破口，不抄全题）
   - `## 接口`：与其他模块的 wikilink
2. 该模块涉及的所有盲区笔记：`status` 从 `待消化` 改为 `待重默`；用户重默通过后再改 `已掌握` 并移入 `99-归档/`（移动时保留正文，用 `vault.py find` 确认无 incoming 依赖断裂）。
3. 重建索引：`vault.py index <vault>`。

## 周期性维护（用户说"整理一下库"时）

1. `vault.py orphans <vault>` → 孤立笔记逐个处理：补关联 wikilink 或移入归档。
2. `00-Inbox/` 清空：逐条分拣或删除。
3. `vault.py index <vault>` 重建索引。
4. 回报格式：`盲区库 X 篇（待消化 A / 待重默 B / 已掌握 C），孤立 D 篇已处理，Inbox 已清空。`
